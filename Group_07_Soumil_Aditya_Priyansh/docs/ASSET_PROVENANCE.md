# Asset provenance

The robot MJCF and robot meshes were inherited from the supplied course/group
project and identify a Stretch robot. They are not claimed as original mesh
design by the students. No new blanket licence is asserted over inherited assets.

The hospital visual package was supplied by the user as Hospital messy room (1).zip,
generated/exported through Nova3D. NOVA3D_SOURCE_MANIFEST.json records the supplied
archive hash and selected source files. models/nova3d_integration_manifest.json
records imported meshes and fitting. The editable original export remains in the
local working archive; this packet includes the runtime OBJ/PNG assets. No third-
party clinical fidelity or independently verified redistribution licence is inferred.

Decorative hospital meshes are visual geometry, separate from the physical
collision geometry and sensor observations. The final task contains 16 objects,
including the subsequently added slipper; the dated integration report describes
the earlier 15-object development stage.
